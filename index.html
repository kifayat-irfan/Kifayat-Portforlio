About

An AI engineer, end to end

I'm Kifayat Irfan, an AI Engineer currently working at Zigron, where I build production AI systems. My work runs the full pipeline — data preparation, model training and evaluation, explainability, backend APIs, and deployed front-ends that real users can open today.

GuardX, my final project for the Hirable AI Bootcamp — an autonomous AI security agent — taught me real-time computer vision under pressure. Since then I've gone deep on medical AI with MedVision AI — a clinical decision-support system designed as a "second pair of eyes" for radiologists — and on RAG systems that answer questions from private document collections without sending data to the cloud.

I care about honest numbers: every accuracy figure on this page is a measured result from a real dataset, and every project below links to the live system or its source code so you can check for yourself.
